# The pinned Python environment of the QZP lean gate (gates 2, 3 and 6).
#
# Users install the package (`pip install llm-anthology`), and pyproject.toml declares the
# version RANGES this code supports. This file pins one resolved set of those plus the test
# toolchain, for two reasons:
#   * the lean gate installs it before the type check, so basedpyright (gate 2) resolves
#     markdown_it, zstandard, ijson and pytest, and before the tests (gate 3);
#   * osv-scanner (gate 6) reads pinned requirements files. Without one it scanned none of
#     the Python dependencies at all.
# Every transitive dependency is pinned too, so the scanner never settles on an old release.
# Dependabot's pip rail keeps these current.
